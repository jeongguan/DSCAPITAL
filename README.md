# Nothing — The Ultimate Luxury

A slick, minimalistic e-commerce website that sells absolutely nothing.

## Features

- 🎨 Luxury minimalistic design with Loro Piana-inspired aesthetics
- 💰 Multiple payment options (one-time, yearly, quarterly, monthly, weekly)
- ⚡ Built with Next.js 14 and TypeScript
- 🎭 Elegant typography using Cormorant Garamond and Inter fonts
- 📱 Fully responsive design

## Pricing Structure

- **One Time**: $999 (Best Value)
- **Yearly**: $1,299 (~$108/mo)
- **Quarterly**: $399 (~$133/mo)
- **Monthly**: $149/mo
- **Weekly**: $49/week (~$196/mo)

*Lump sum payments are cheaper, smaller regular payments are more expensive.*

## Deploy to Render

1. Push this repository to GitHub
2. Connect your GitHub repository to Render
3. Render will automatically detect the `render.yaml` configuration
4. Click "Deploy" and your site will be live!

Alternatively, you can manually create a new Web Service on Render:
- **Build Command**: `npm install && npm run build`
- **Start Command**: `npm start`
- **Environment Variable**: `NODE_ENV=production`

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
